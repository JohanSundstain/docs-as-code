# Анализатор резюме

Анализатор резюме — это сервис на основе искусственного интеллекта, который автоматически анализирует резюме кандидатов, извлекает ключевую информацию и помогает оценить соответствие кандидата требованиям вакансии.

**Основные пользователи:**
- Соискатель — пользователь, который хочет проанализировать своё резюме.
- HR-специалист — пользователь, который хочет быстрее обрабатывать резюме кандидатов.

**Основные функции:**
- Загрузка резюме в систему.
- Автоматическое извлечение навыков, образования и опыта работы.
- Сравнение информации из резюме с требованиями вакансии.
- Формирование результата анализа с рекомендациями по улучшению резюме.

## Комплект документации

1. **Описание проекта** — предназначено для всех участников разработки и содержит общую информацию о назначении и возможностях системы.
2. **Требования** — предназначены для разработчиков и тестировщиков, описывают функциональные возможности системы и критерии их проверки.
3. **Архитектура системы** — предназначена для разработчиков и описывает основные компоненты системы и их взаимодействие.
4. **Документация API** — предназначена для разработчиков и описывает способы взаимодействия приложения с другими компонентами системы.
5. **Документация ML-модели** — предназначена для разработчиков и специалистов по машинному обучению, описывает используемую модель и принцип анализа резюме.
6. **Руководство пользователя** — предназначено для соискателей и HR-специалистов и объясняет, как пользоваться сервисом.
