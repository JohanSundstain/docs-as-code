# API

API анализатора резюме предоставляет доступ к функциям загрузки и анализа резюме, извлечения информации о кандидатах и сравнения резюме с требованиями вакансий.

## Основные операции

- `POST /resumes` — загрузить резюме и выполнить анализ с помощью ML-модели;
- `GET /resumes/{id}` — получить результаты анализа резюме по идентификатору;
- `POST /resumes/{id}/compare` — сравнить резюме с требованиями вакансии.

## Спецификация

Полное описание API находится в файле `openapi.yaml` и содержит параметры запросов, структуры ответов и возможные ошибки.
