# Data Sheet

## Общая информация

**Название датасета:**  
Resume Dataset (`datasetmaster/resumes`).

**Источник:**  
[Hugging Face — datasetmaster/resumes](https://huggingface.co/datasets/datasetmaster/resumes).

**Назначение:**  
Датасет предназначен для обучения и оценки NLP-моделей, которые анализируют резюме и извлекают информацию о кандидатах.

## Состав данных

**Объём:**  
4817 записей, общий размер — около 16,3 МБ.

**Тип данных:**  
Текстовые данные в формате JSON. Датасет содержит реальные и синтетически сгенерированные резюме.

**Основные поля / признаки:**  
Структурированные сведения из резюме. Точный перечень полей в доступном описании не указан.

## Получение данных

Датасет объединяет реальные резюме, собранные из различных источников, и синтетические резюме, созданные с помощью Python-скриптов и библиотеки Faker. Более подробная информация о процессе сбора не указана.

## Предобработка

Данные нормализованы к единой структуре JSON. Другие этапы предобработки не указаны.

## Ограничения

- Некоторые поля, например сертификаты и публикации, заполнены не во всех записях.
- Реальные резюме могут содержать неполные данные.
- Различия в форматах резюме могут приводить к неоднородности данных.
- Использование синтетических данных может снижать реалистичность обучающих примеров.

## Использование в проекте

Датасет может использоваться для дополнительной оценки качества анализатора резюме и потенциального дообучения модели Resume NER. Он позволит проверять, насколько корректно система извлекает информацию о кандидатах и обрабатывает резюме разной структуры.
