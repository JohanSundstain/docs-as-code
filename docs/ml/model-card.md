# Model Card

## Общая информация

**Название модели:**  
Resume NER — Structured Resume Information Extraction.

**Источник:**  
[Hugging Face](https://huggingface.co/oksomu/resume-ner).

**Автор / организация:**  
Somasundaram Ayyappan. Организация автора не указана.

**Задача модели:**  
Распознавание именованных сущностей (NER) и извлечение структурированной информации из резюме.

**Язык:**  
Английский.

## Использование в проекте

Модель используется в проекте «Анализатор резюме» для автоматического извлечения структурированной информации из резюме кандидатов: навыков, образования, опыта работы и контактных данных.

Пользователь загружает резюме через endpoint `POST /resumes`. Backend извлекает текст из документа и передаёт его модели для анализа. Полученные данные обрабатываются и сохраняются системой.

Результат анализа можно получить по идентификатору резюме через `GET /resumes/{id}`. Для сравнения навыков и опыта кандидата с требованиями вакансии используется endpoint `POST /resumes/{id}/compare`.
Модель будет использоваться в анализаторе резюме для автоматического извлечения навыков, образования, опыта работы и контактной информации кандидатов.

## Входные данные

Текст резюме на английском языке, предварительно извлечённый из документа PDF или DOCX.

## Выходные данные

Структурированные данные: имя, электронная почта, телефон, местоположение, навыки, образование, опыт работы и другие сведения о кандидате.

## Метрики качества

Авторы указывают следующие результаты:
- Entity F1 — 97,77%.
- Structured Micro F1 — 97,88%.
- Clean Resume F1 — 99,18%.
- Noisy Resume F1 — 69,24%.

## Ограничения

- Поддерживается только английский язык.
- Максимальная длина контекста — 512 токенов на фрагмент.
- Для сканированных PDF требуется предварительное распознавание текста (OCR).
- При обработке документов с двумя колонками возможно нарушение структуры текста.
- На зашумлённых данных качество заметно снижается.

## Не рекомендуется использовать

Модель не предназначена для анализа резюме на других языках, оценки профессиональных качеств кандидата или принятия автоматических решений о найме. Также не рекомендуется использовать её напрямую для обработки сканированных документов без предварительного OCR.
